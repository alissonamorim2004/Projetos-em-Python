# Projetos em Python

Código escrito na fase de aprendizado, sem framework e sem assistência —
resolvendo cada problema do zero.

## Projetos com aplicação

**Sistema de Recomendação** — filtragem por similaridade sobre o dataset
MovieLens, com cálculo de proximidade entre usuários e geração de sugestões.

**Sistema de Libras** — reconhecimento de sinais com modelo de classificação de
imagem. Primeira versão do que viria a ser meu TCC, depois reconstruído em
tempo real com CNN.
